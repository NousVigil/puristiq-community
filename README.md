# PuristIQ Community

This is the public place for the **PuristIQ** app: a free, offline-first app that scans food and pet-food labels and flags ingredients that matter for your health profile. No ads, no account, no tracking.

The app's source code is private. This repository holds **no code**. It exists so that everyone who uses PuristIQ can ask for things in one place, and so the roadmap follows what the community actually wants.

## How to take part

- **Ask for a feature:** [open a feature request](../../issues/new?template=feature_request.yml)
- **Ask for another AI provider** (the app currently supports the OpenAI API, which also covers local models such as Ollama and LM Studio): [open an AI provider request](../../issues/new?template=ai_provider_request.yml)
- **Report a bug:** [open a bug report](../../issues/new?template=bug_report.yml)
- **Report a missing or wrong ingredient:** [open a data report](../../issues/new?template=ingredient_data.yml)
- **Vote:** add a 👍 reaction to an existing issue instead of opening a duplicate. We use 👍 counts to decide what to build next.

You can write in any of the app's 24 languages; English helps more people read it.

No GitHub account? Write to **hello@puristiq.net** and we will add your request here for you.

## Please never post

- Your health conditions, allergies or other medical information
- API keys or any other secret
- Photos that show personal information (receipts, faces, addresses)
